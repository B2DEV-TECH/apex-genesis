# APEX Genesis

**Can a database evolve its own user interface?**

*Interfaces are born. The database decides who survives.*

An experimental interface evolution laboratory by B2DEV TECH and Geraldo Viana Jr.
Oracle PL/SQL owns the genetic algorithm and history. A shared constrained renderer
turns validated genomes into functional synthetic dashboards. Optional AI proposes
mutations; independent rules select survivors.

**Development status:** implementation in progress. No completed Claude comparison,
public release, video, or 100-generation result is claimed by this initial document.

See the [engineering design](docs/architecture/design.md) and
[execution plan](docs/implementation-plan.md). Original project code is Apache-2.0;
Oracle and provider products retain their own terms. This is an independent project,
without Oracle or Anthropic endorsement.
