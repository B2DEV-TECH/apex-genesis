## AI evidence and blockers

The Anthropic adapter is implemented and tested with mocked proposals and concurrent
Oracle workers. Documentation reviewed 2026-10-20 lists claude-haiku-5-5 and a
short-prompt starting rate of $0.10/$0.50 per million input/output tokens. Runtime
model lookup, current reviewed rates, secure credentials and run opt-in remain
required. Provider requests, model tokens and direct API cost for published runs
are all zero. No invoice verification is claimed.

The owner has not yet supplied/configured the key and explicit paid-run authorization.
Consequently live authentication, ACL/wallet/TLS access, actual provider failure
behavior and the target 100-generation GA_ONLY/GA_HAIKU competition are blocked.
No mocked AI population appears in the public experimental results. US$1 is a
suggested ceiling, not authorization. Optional provider failure preserves offline use.

## Remaining alpha limitations

- The default weighted fitness is fixed in source. Alternate fitness configurations,
  Pareto/rank selection and adaptive AI policies require separately versioned work.
- Basic run controls are exposed. Advanced operator/time-limit fields are owner
  configuration before initialization; full UI controls for these and run-N execution
  are not yet exposed. Checkpoint duplication exists in the database/callback.
- Family exploration uses three-generation windows, zoom, scroll and population
  selection. Global node search, extinction aggregation and richer graph filters
  are not yet implemented.
- Human preferences have separate storage; an interactive voting workflow is not
  yet implemented. No public vote service is deployed.
- No full CPU/memory profile, human task study, alternate provider, generated winner
  materialization or broad Oracle/APEX compatibility claim.
- Automatic proxies favor large text and long single-column layouts. Equal candidate
  slots differ from equal unique browser work. Five seeds are descriptive only.

This is an implemented, evidence-bearing **alpha**, not completion of every ambition
in the master research brief. The remaining features and AI evidence stay explicit.
